# 旁白写作说明（混沌法典 · 全卷视频）

## 声音与语气
- 配音是**低沉浑厚、略带沧桑的老者男声**，语速缓慢，像一位活了万年的修士在讲述法典。
- 文风：半文半白，克制、有画面感；短句为主，句与句之间留呼吸。可以引咒语（“咒曰：……”），但不要堆砌辞藻。
- 每段都要落到**真实的规律**上：这一式背后是什么规则，画面里能看到什么规律（对称、自相似、同步、守恒、临界……）。不要编造科学事实；不确定的数字不要说。
- 不出现英文字母和阿拉伯数字（TTS 会读错）：数字写成汉字（“二十八”“三分之八”“十的十二次方”），人名用通行中文译名（洛伦兹、霍普夫、庞加莱、曼德博），公式用口语描述（“自乘，再加上自己”）。
- 不要写“如画面所示”“我们可以看到”这种讲解腔，改用叙述：“剑阵绕着两个看不见的眼盘旋……”。

## 长度
- 开场：约 220–280 字。
- 每境开篇：约 100–140 字（境界设定 + 造诣 + 这一境画面的维度/气质）。
- 每式：约 70–110 字（约 18–25 秒）。第一句点名：“X 境，某某。”或“某某。”可变化，别每段同一模板。
- 收尾：约 150–220 字。

## 素材
- `data/spells.json`：每式的 rule / chant / eff / ess / ctr / cam / fact（以 realm 字段为准的所属境界）。
- `data/xian_<realm>.json`：仙侠意象（画面里修仙世界的样子）。
- `src/ink.js` 中 REALMS：每境的 lore / img / zaoNote / note。
- 画面实际内容（尤其高境界的数学意象）看 `src/spells/d_<realm>.js` 的注释与 hud 文本，旁白要与画面一致（例如 tesseract 画面会依次出现超立方体、二十四胞体、六百胞体、一百二十胞体）。
- 第一集旧旁白可参考：/home/claude/xiu/x01/mkscript.py。

## 输出
写入 `narration/<realm>.json`：
```json
{ "intro": "……境界开篇……", "spells": { "key": "……", "key2": "……" } }
```
开场与收尾写入 `narration/_open.json`：`{ "open": "……", "close": "……" }`（只由负责炼气的人写）。
键必须与 spells.json 中该境的键一一对应、一个不漏。
